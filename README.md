# Falcon Swift (showcase)

A parametric, 3D-printable swept-wing sport jet RC plane. One Python script generates every print-ready STL part, so the whole design changes by editing a few numbers.

> **This is a showcase repository.** The generator and STL files are private. Request access via [LinkedIn](https://id.linkedin.com/in/ferdinand-klasse).

![Preview](preview.png)

## Design
| | |
|---|---|
| Wingspan | 520 mm |
| Length | 515 mm |
| Wing area | 5.6 dm² |
| Leading-edge sweep | 30° |
| CG | 25–30% MAC |
| Estimated flying weight | about 150 g (estimate, not weighed) |

Conventional layout (aileron, elevator, rudder). Printed in lightweight PLA on a Qidi 550 with 0.6 mm line width and a PETG motor plate.

## Tech
Python and NumPy, STL export, FDM printing.
